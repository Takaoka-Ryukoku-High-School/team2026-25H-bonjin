# 今日の段取り

Python と Flet で作った、先生・生徒向けのブラウザ用ダッシュボードです。先生が時間割・通知・課題・行事を登録し、生徒は閲覧できます。テスト予定は先生が表形式で作成・編集し、配信した予定だけ生徒が閲覧できます。時間割は全クラス共通で曜日・時限・授業内容・担当教師を設定でき、日付指定の特別日課や休校で通常時間割を上書きできます。生徒のタスクはアカウントごとに保存されます。先生と生徒の個人チャット、クラス別グループチャットにも対応しています。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

開発中はログインせず、起動時に先生用・生徒用を選べます。開発モードは認証を行わないため、画面にアクセスできる人は先生用機能も使えます。開発中のローカル利用に限り、本番運用や他の人に公開する場合はログインを有効にしてください。

```bash
python main.py --login
```

ログインを有効にする場合、まず `python main.py create-teacher` で先生アカウントを作成します。ユーザー名と8文字以上のパスワードを対話形式で入力します。先生はログイン後、「クラス管理」からクラスと生徒アカウントを作成し、初期パスワードを生徒に安全な方法で共有してください。生徒は先生から発行されたアカウントでログインします。

データベースは `~/.daily_note.sqlite3` に作成されます。時間割などの学校情報とチャットは共有され、タスクは本人だけが参照・変更できます。既存の `~/.daily_note_tasks.json` がある場合、時間割・通知・テスト・課題・カレンダーの情報を初回起動時に移行します。旧タスクは所有者を特定できないため、自動移行しません。

時間割は、アプリが起動している間、サーバーのローカル時刻で月曜分を金曜日15時、火曜分を水曜日15時、水曜分と金曜分を木曜日15時に生徒側へ自動配信します。曜日ごとに配信済みの時間割が表示されます。先生用画面からの手動配信では、従来どおり全曜日を配信できます。

先生は「通知」から通知内容と日付・時刻（例: `2026-11-10` と `07:00`）を指定して登録でき、登録後も内容や日時を編集できます。通知は生徒側の通知一覧に表示されます。

先生は「テスト管理」で学年を選び、教科ごとに試験日・開始時刻・試験範囲を入力できます。1年生には数学・英語・言語文化・現代国・地基・歴史・人間学・家庭科があらかじめ表示されます。2・3年生は教科を追加して表を作成できます。「保存して生徒へ配信」を押すと、そのテストを保存して生徒側に表示します。生徒側では配信済みの全学年のテストを確認できます。

ブラウザで使うには、起動しているアプリへアクセスできる環境が必要です。インターネットに公開する場合は、HTTPSなどの通信保護を備えた信頼できる構成で運用してください。
